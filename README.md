# 🦠 COVID-19 Global Vaccination Dashboard

A data analytics and visualization project built using **Power BI** to track and analyze 
global COVID-19 vaccination progress across countries worldwide.

## 📊 Project Overview

This project visualizes country-wise COVID-19 vaccination data sourced from the 
**World Health Organization (WHO)**. It provides interactive insights into vaccination 
trends, coverage rates, and vaccine distribution across the globe.

## 📁 Files

| File | Description |
|------|-------------|
| `CORONA.pbix` | Power BI Dashboard file |
| `CORONA.xlsx` | Source dataset with vaccination data |

## 📌 Key Metrics Tracked

- Total Vaccinations per Country
- People Vaccinated (Partial & Full)
- Daily Vaccination Rate
- Vaccinations per Hundred Population
- Vaccination Rate % by Country
- Vaccine brands used per country (Pfizer, AstraZeneca, J&J, Sinopharm, etc.)

## 🌍 Data Source

- **Source:** World Health Organization (WHO)  
- **Link:** https://covid19.who.int/  
- **Coverage:** Global — 180+ countries

## 🛠️ Tools Used

- Microsoft Power BI (Dashboard & Visualization)
- Microsoft Excel (Data storage & preprocessing)

## 🚀 How to Use

1. Clone or download this repository
2. Open `CORONA.pbix` in **Power BI Desktop**
3. The dashboard will load with all visuals and data already connected

## 📈 Dashboard Highlights

- Country-level vaccination comparison
- Time-series trends of daily vaccinations
- Fully vs. partially vaccinated population breakdown
- Vaccination rate per hundred for fair cross-country comparison
